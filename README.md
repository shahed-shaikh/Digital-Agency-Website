NORTHSTAR is a creative studio website built with HTML5, CSS3, and Tailwind CSS. Its dark palette, lime accents, and refined typography create a distinctive digital presence.

The homepage introduces the studio through a hero section, animated text marquee, and About section. Statistics highlight experience, projects, global partners, and industries explored. Five services are presented: Brand Strategy, Creative Direction, Digital Experiences, Web Development, and Digital Campaigns.

The project gallery features MONOCHROME, FORM HOUSE, WORKSPACE, and OBJECT STUDIO. A four-stage process—Discover, Strategy, Create, and Deliver—explains how ideas become meaningful brand and digital experiences. The page also includes a creative quote, contact section, and footer with navigation and social links.

Built with Tailwind CSS and custom CSS, the website demonstrates responsive layouts, mobile navigation, hover transitions, image effects, animated typography, a moving marquee, and scroll-reveal effects. The result is a polished portfolio focused on creativity, clarity, and visual storytelling.
